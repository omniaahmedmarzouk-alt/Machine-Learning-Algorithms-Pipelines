# 🚀 Machine Learning Basics & Pipelines

Welcome to my Machine Learning repository! This workspace contains my implementations of foundational ML algorithms from scratch, along with end-to-end data pipelines.

## 📂 Projects Included:

1. **[ML Algorithms From Scratch & Dashboard](./Implementation)** - Implementation of Linear & Logistic Regression from scratch (Gradient Descent, Sigmoid, Log Loss) with a dynamic Streamlit dashboard to train and test models instantly.
2. **[Adult Income Classification Pipeline](./Census_Income_Project)** - An end-to-end pipeline (EDA, Feature Engineering, Sklearn Logistic Regression) deployed as an interactive web app.
3. **[Decision Tree & Overfitting Analysis](./Decision_Tree_Overfitting_Analysis)** - A comprehensive analytical study on model overfitting using University Admission data. It demonstrates the pitfalls of unconstrained models (unpruned trees & high-degree Polynomial Regression) and solves them using Tree Pruning (`max_depth`) and Ensemble Learning (Random Forest), complete with an interactive Streamlit web app.
4. **[Mall Customer Segmentation App](./Mall_Customer_Segmentation_Project)** - An Unsupervised Learning project applying **K-Means Clustering** to segment mall customers based on purchasing behavior. Features Exploratory Data Analysis (EDA), mathematical cluster validation using the **Elbow Method** and **Silhouette Analysis**, and an interactive Streamlit web app to predict customer personas instantly.
