# Online Retail ML Pipeline

## Overview
End-to-end ML pipeline built on the UCI Online Retail II dataset.

## Pipeline Steps
1. **Data Cleaning** — Handling cancellations, invalid records, and outliers
2. **Feature Engineering** — RFM analysis and customer segmentation
3. **Clustering** — K-Means to discover natural customer segments (K=4)
4. **Supervised Learning** — Random Forest to predict high-value customers (95% accuracy)
5. **Deployment** — Streamlit app for real-time predictions

## Dataset
UCI Online Retail II — UK-based online gift retailer transactions (2009–2011)

## Tech Stack
- Python, Pandas, Scikit-learn
- Matplotlib, Seaborn
- Streamlit, Joblib
